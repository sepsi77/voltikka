# Contract detail seller UTM parameters

Add UTM query parameters to every external seller link labelled "Siirry myyjän sivuille" on contract detail pages.

Required values:
- `utm_source=voltikka.fi`
- `utm_medium=referral`
- `utm_campaign=voltikka_sahkovertailu`

Preserve existing seller query parameters and URL fragments. Do not add the parameters to internal fallback links.
