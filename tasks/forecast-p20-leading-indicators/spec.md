# Frozen offline p20 leading-indicator study

This protocol is frozen before new metrics. The April 8–September 13, 2026 export period was already inspected. This is retrospective evidence, not an untouched holdout.

## Inputs and ownership
Use only the verified pinned `tasks/supplier-premium-coverage/export-20260913T094138Z`: 477 unit statistics, 2,239 futures, 1,314 stored forecasts (the last are provenance evidence, not new labels). Scope: public fixed_term_6/12/24, energy_price, null consumption, unit_statistics_v1. Fields: p20_value, median_value, p80_value. Select latest statistic ID per basis/term/date before validation. All three finite quantiles, including zero, must satisfy p20 <= median <= p80; reject invalid vectors, never sort them. No price fill, annual-v2 statistics, or observed/canonical feature/target bridge. p20 is a percentile, not the mean of the cheapest 20%, and not a fixed company cohort. Promotions and product turnover remain uncontrolled.

## Cohorts and fits
Primary horizon 30 days, secondary 14; input change always exactly 7 days. Current, lag and target statistics have the same basis. Features never read target values. Require the native intersection of all three quantiles and rolling-H inputs for all A and B models. Retain only complete issue days with all three terms. A fixed-basket sensitivity uses that intersection further restricted to complete fixed-basket inputs, with all controls refitted on that same cohort; report if different. B does not use fixed basket.

Fixed July 27, 2026 transfer: train only observed pairs whose target is STRICTLY before July 27; canonical test issue >= July 27 and target <= September 13. With seven-day canonical history the maximum is 12 days/36 term rows for 30 days, 28 days/84 rows for 14. No v3 gap model or its ten-day EWMA warmup gate is included: training can start earlier than the previous experiment. Also run same-basis rolling origins: training target strictly before each issue, observed and canonical regimes reported separately. At least 20 unique training issue DAYS for every fit; no borrowing to repair canonical unavailability.

Primary fits pool all terms with shared slopes, equal row weights, no term dummies. Prespecified sensitivity fits each duration independently with the same 20-day rule; no pooled observations may enter a per-term fit. Run both horizons and regimes for both fit scopes, without selecting a winner. Ridge minimizes mean squared target-change error + 1.0 * sum(standardized slopes squared). Training population mean/scales only; constant features map to zero. Unpenalized standardized intercept equals mean target change. No hyperparameter, threshold, lag or feature search.

## A: futures increment by quantile
Fit separate target delta q(t+h)-q(t) for p20, median, p80. Models: unchanged, intercept-only, q-history [q(t)-q(t-7)], q-history + rolling H change. Single sensitivity: q-history + fixed-basket H change on its matched cohort, with unchanged/intercept/history/rolling comparisons retained. Rolling H uses each endpoint's next-full-month basket. Fixed basket selects next full month and duration at issue, using exactly the same months and actual month-day weights at latest trade < issue and latest trade < issue-7. FI Base, month-quarter-year fallback, complete coverage, EUR/MWh /10 * VAT 1.255. No newer vintage or missing-strip fill. Negative features are valid.

## B: leading p20 information for the median
Target median(t+h)-median(t). Models: unchanged; intercept; median-history; median-history + p20 change; median-history + spread [median(t)-p20(t)]; median-history + p20 change + rolling H change. The combined model is fixed now, not selected after results. Compare p20 additions to history and intercept; compare combined to history+p20 change to isolate incremental futures value. Spread is a contemporaneous relational gap, not a nominal-level response fit. Quantile changes over the same past seven days are a contemporaneous diagnostic only, never lead evidence.
