## Design rules you must keep (summary; the spec is complete)

- No cards, panels, pills, badges, shadows, gradients or glass. Structure = display headings with a wavy fox underline, inked hairlines, dotted leaders, sparkle marks.
- Fox never next to a contract, a seller or a seller price. Villagers never next to contracts.
- Category meaning uses the glyph shape + name, not colour only.
- Controls must look like controls: real radios/checkboxes (`--radius-control` 5), underlined fields with `--color-field-edge`, visible focus.
- Fox orange `--color-fox` only for marks and text 24px and up; small fox-colour text uses `--color-fox-deep`.
- Never mention Energiavirasto in public copy. Do not change Finnish copy that the code comments call "locked". Keep live content parity: every fact, link and text the live page has must stay.

## Rules for the work

- Edit only the files your task owns. If you must change a file that another agent owns, stop and say so in your report.
- Shared components (`x-site.*`, `x-ink.*`, `x-card.*`, `contract-card`, partials used by the listing): reuse them. - Update the closest `AGENTS.md` (and its `CLAUDE.md` twin when it is a separate real file) for decisions that future agents must not undo.
- End with a short report: files changed, what you verified (with screenshot paths), test results, open items and any deviation from the board with its reason.
