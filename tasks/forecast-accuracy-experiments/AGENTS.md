# Offline forecast accuracy experiment

This folder owns only offline research. Do not edit application files or original exports, access production, replace a database, install dependencies, or deploy from this task.

- `spec.md` and `spec.sha256` preserve definitions frozen before this task's metrics. Primary is a 30-day target with seven-day inputs; 14-day inputs and targets are separate secondary tests, not a winner search.
- `scripts/experiment.py` imports the prior verified export loader without running its writers. It reuses hash-verified exact v3 gap rows. The new fixed basket prices identical issue-selected delivery months at both strictly earlier trade vintages with identical actual-day weights.
- Learned models fit target changes only, share coefficients across 6/12/24 terms, use training-standardized ridge penalty 1.0 and unpenalized intercept, and share exact training/test identities. At least 20 prior issue DAYS are required. The frozen July 27 observed-to-canonical transfer is an explicit continuity assumption; same-basis canonical rolling fits remain unavailable.
- `scripts/verify.py` independently checks Decimal daily-expanded basket prices, raw statistic IDs, cutoff and cohort identities, ridge normal equations, synthetic edge cases and metrics. The actual PHP evidence is reused by verified artifact hash, not rerun against a database.
- `scripts/report.py` renders `report/report.md`. `scripts/reproduce.py` repeats calculation, verification and rendering twice and checks identical outputs and preserved export hashes. Run it from the repository root with Python 3.11 or later; only the standard library is used.
- `report/artifacts/` retains every feature, fit, prediction, exclusion, metric and source hash. No production archived-vintage collector is deployed for this experiment.
- The canonical holdout was already inspected by prior research. It is retrospective and contaminated by prior analysis, not untouched out-of-sample proof. The main paired cohort has only 12 issue days; all its 30-day windows overlap. Fixed basket loses to rolling and retail-only. No application recommendation follows from the pooled gains.
- Controlled-index construction belongs to `tasks/retail-index-composition-test`, not this task. Do not silently change this public-median target to the controlled-index target.

## Approved intercept-only continuation

- `intercept-spec.md` and `intercept-spec.sha256` freeze a separate post-hoc diagnostic before its metrics. The user approved this control after the original report. It distinguishes a historical mean-change prediction from feature adjustments; it does not add a predeclared model to the original experiment. Keep the original spec, scripts and report/artifacts unchanged. `intercept-inputs.json` pins their bytes.
- `scripts/intercept_experiment.py` reads the exact original fit training IDs and original test predictions. Its only fitted parameter is the equal-row mean of target minus current, shared across all terms. Each mean must match all three original standardized intercepts within 1e-10, not raw-feature b0. Original models are not refit. All input/target cohorts, strict label cutoffs and the 20-issue-day gate stay unchanged; strict canonical rolling remains unavailable.
- `scripts/verify_intercept.py` independently rebuilds means from raw export statistic IDs and Decimal prices. It checks balanced terms, every original prediction field, all paired metrics and adjustments, common subsets, and constant/changing-mean synthetic data. It runs original verification with its writer disabled. No original output is rewritten.
- `scripts/reproduce_intercept.py` runs only the additive writer/verifier twice and checks eight byte-identical new outputs plus all pinned original/source hashes. New evidence is in `report/intercept-artifacts/`; the separate report is `report/intercept-report.md`.
- Primary intercept-only MAE is 0.484324 c/kWh. Retail lowers it by only 0.004902; rolling lowers it by 0.047990; basket raises it by 0.001437. Rolling beats intercept for all three primary terms, but only six months beats unchanged. Older observed 30-day rolling loses to intercept; 14-day rolling beats it. These paired error differences are not causal fractions of gain. Prior holdout inspection, overlapping windows, revised inputs and regime transfer still prevent independent validation or production adoption. No prospective collector or new experiment starts here.
