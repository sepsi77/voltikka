# Fixed-delivery lagged futures levels (offline)

## Frozen protocol
Test whether older futures price levels improve H + N − R numerical and directional forecasts. This is not a correlation-of-changes test. Use only the complete verified export `supplier-premium-coverage/export-20260913T094138Z` (April 8–September 13, 2026), retained actual-PHP v3 replay, and existing hedge helpers.

Primary horizon: 30 calendar days. Do not include the optional 14-day horizon in this bounded unit. Terms: 6/12/24 months; quantile: median. Fixed lag grid: 0/7/14/21/30 calendar days. Alpha .25; lambda .30; minimum 10 usable prior days; public signal and actual thresholds both .15. No parameter selection, regression, intercept, or other fit.

At retail date t, every lag uses the same next-full-month delivery basket of the specified duration. Select the latest FI Base trade strictly before t−L. Use only that vintage, month→quarter→year fallback, actual month days and VAT 1.255. Reject missing full strips; never move the basket back or use newer trades. Recompute every historical H_L(s) at its own retail date s. Learn EWMA of R(s)−H_L(s), strictly s<t. Use corrected v3 method/basis/ownership chronology: observed prefix before first as-of canonical unit date, then canonical only; invalid presence owns dates, no fallback. Targets are exact-date and same basis/method as issue. Continuity is an assumption.

Report native eligibility and missing-current-H/history-warmup counts. Primary comparison uses the intersection of identical issue/target/term/median rows across all five lags with each lag's native history. Sensitivity recomputes all premiums on the exact intersection of historical dates per forecast, requiring at least 10 common days. Keep observed and canonical regimes separate. Include full canonical mature issues and stored-v2 matched dates separately; retain original v2 only as saved reference. Report MAE/RMSE/bias and correct/wrong_way/missed_move/false_move per term and all, unchanged-price and direction-only always-up/down controls, class balance, and history bounds/counts.

New signals use unrounded expected change, then save four decimals; outcomes use four-decimal actual minus current. Independently compare Decimal classification from saved four-decimal change and list disagreements, without rewriting originals. Predeclared diagnostics: H_L>H_0, fair-gap sign changes, August 8/9 six-month strong-fall cases; retain H/N/R decomposition and compensation.
