# Deferred contract import completion

Implement local-only durable same-day completion after a successful full acquisition and required initial statistics/invalidation, when exact interpretation targets remain pending or the existing two-attempt cache refresh ends in a typed conflict. Keep current cache validation and HTTP 503 recovery.

Use versioned checkpoint JSON, full-run UUID compare-and-set ownership, exact observation/snapshot/dispatch provenance, bounded claimed polls (60 checks, two hours), and a shared finite required-statistics/cache execution lock. Correct statistics ordering comes from an optional callback inside the existing statistics transaction: lock the checkpoint row and validate current run/claim/date/source/active identities before any deletion, holding that row lock through statistics commit. The finite cache lock is an optimization, not a correctness bound; no process alarm is needed. No schema, flags, queue workflow, publisher mutex, automatic full fetch, historical recalculation, or production actions.

Ready must prove current active coverage, publications, statistics and cache generation at the completion write boundary. Later morning readers keep existing forecast scope and publication-only statistics recovery for new and legacy manifests; they must not pin all-market publications or the cache UUID forever. Scoped runs never insert or replace global readiness. Their statistics transaction locks an existing checkpoint row or performs the missing-key locking read without creating a row. Genuine failures, interrupted write claims, stale dates and exhausted bounds fail closed. Dry run is read-only. Legacy failed records cannot resume without proof. Add concurrency and behavior tests and document release approval needs.
