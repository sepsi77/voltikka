# Read-only local pricing preflight

Read `../comparison-safety.md` before changing or running the comparison scripts. The manager owns real export and comparison execution after review. The runner must use one selected code tree per fresh process, vendor-only dependency loading, selected-tree App/Database reflection proof, and SQLite PDO READONLY plus query_only. Never boot the application kernel, load credentials, mutate production, replace the local database, or manufacture V5 facts. Output is private and complete; ranking is recomputed engine order, not observed live cache order.

The comparator requires a complete sibling export manifest, verified snapshot hash and matching raw active row count before Laravel loading. It checks the loaded joined count before pricing and reports orphan rows separately. See the mandatory manifest section in `../comparison-safety.md`. It does not consume summary.json values.

Every full raw calculated-cost outcome now passes through the selected tree's `ContractPricingViewData::fromArray()` before `withoutProse`. Reflection and loaded-code hashes include that reader. Each phase records checked/valid/error counts and at most 100 error details (contract ID, closed reason and safe exception class only). Validation never changes financial rows or stops baseline diagnostics. Missing validation is not a pass. `report.php --require-candidate-transport` writes the diagnostic report, then exits 2 if candidate validation is missing, incomplete or has any error. The manager release gate must require `candidate_transport_ready=true` in addition to all existing economic, cold/warm, manifest, isolation and read-only checks. See `../strict-transport-release.md`. This check does not turn the prose-stripped audit projection into a public transport payload.

`smoke.php` is synthetic only. It does not validate real-data impact or baseline compatibility. `export-smoke.php` checks safe index fidelity, statistics, graph anomalies and legacy NULL-pointer diagnostics without network or application boot.

The runner records bounded SQL shapes and individual times, never bindings. Slow-query plans use the same read-only PDO; a trusted PHP diagnostic callback can compare isolated copies without changing the full-comparison manifest rules. Callback time is included in wall time, not Laravel SQL time. See `../query-profile.md` for the measured SQLite planner defect and exact evidence paths.

Future exports use the original full-column NONUNIQUE lookup-index strategy for every source index, including collated text primary/unique keys and decimal unique keys. They do not mirror MySQL constraints. Source index metadata and explicit primary-key duplicate, graph and data checks remain intact. Unsupported index shapes still stop export. Required metadata must match the actual schema SELECT fields; optional expression/partial fields are not required. ANALYZE runs before sealing only the new private file: measurements show statistics alone fix the planner defect, while optional uniqueness does not. See the appended manager decision in `../query-profile.md`. Legacy NULL analysis pointers remain separate metadata, not mismatches by themselves. The original sealed export and diagnostic variants must stay unchanged.
